What is this tool for? In project.json inside sb3 files, any time variable or list is refernced, it's done by both the id and the name. Usually they point to the same variable, but sometimes due to editor bugs they can go out of sync. For example, they could go out of sync when copying scripts between sprites or backpacking scripts. And which of them Scratch uses? In the past Scratch preferred linking them by ids, even if names didn't match. After update in mid-2026 it got changed, which broke a lot of projects, some completely, some is sublte ways. For example https://scratch.mit.edu/projects/637062431/ got broken completely.

You can use this tool to check if the project is affected.
